# Bing Bong Voice Override

A BepInEx mod for [PEAK](https://store.steampowered.com/app/3527290/PEAK/) that turns Bing Bong into a fully programmable speaker. Drop your own audio in, point the mod at YouTube/SoundCloud links, and let Bing Bong play any sound you want with native subtitles, native mouth animation, and optional global music playback.

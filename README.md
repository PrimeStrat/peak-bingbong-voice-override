# Bing Bong Voice Override

A BepInEx mod for [PEAK](https://store.steampowered.com/app/3527290/PEAK/) that turns Bing Bong into a fully programmable speaker. Drop your own audio in along with customizable subtitles, then let Bing Bong speak!
